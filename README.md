## 香港 CMIN2 到底优化了什么，谁其实不需要

CMIN2 优化的是中国移动方向。它不管电信和联通方向的事，那两张网走的是另外两条链路。

内地到香港的线路质量，取决于你的运营商把流量交给谁。普通国际出口在晚高峰容易拥塞，表现为延迟从 30ms 跳到 150ms、丢包、SSH 输入一顿一顿。三网精品线路的做法是让每家运营商用自己的高端产品对接：电信 CN2 GIA、联通 AS9929、移动 CMIN2。GoMami 的香港机型三张网都接了，官方广告页把这一组合写成「三网 CN2 GIA / 9929 / CMIN2，香港直连，无惧晚高峰」。第三方整理给出的路径更细一层：回程三网精品，去程走主干直连（电信 163、移动 CMI、联通 10099）。

延迟方面有两组数字，口径差别很大，放在一起看才不失真：

- 官方口径：香港节点 **6ms**，注明是「三网运营商中最快省份实测数据」——最优省份的最优值，不是你家的值。
- 第三方实测：一篇测评对 HKG.Pulse.Mini 做了全国 TCPing，三网各自走精品线路，平均落在 **40ms 左右**。

那台 Pulse Mini 是 2 核 EPYC 7763 / 4GB 内存 / 40GB NVMe，机房位置香港葵青，KVM 虚拟化，NAT 类型 Full Cone，TCP 拥塞控制为 BBR。Geekbench 5 单核 1062、多核 2027；4K 随机读写约 242 MB/s，1M 块读 3.07 GB/s、写 3.27 GB/s。对一台 $49/月的香港机器，这个成绩属于够用且不虚标的区间。

谁不需要它：用户主要在欧美，或者只是想要个便宜的海外落地机跑爬虫，CMIN2 这部分溢价完全用不上，香港机房也不是最优解。主站用户在国内、尤其移动占比高的站点，或者你在国内用移动宽带远程连香港做开发，这笔钱才花得有意义。
